# からだの連鎖 — 姿勢応答ラボ

視覚刺激に対する2リンク倒立振子の応答を、モデルA（力学的結合のみ）とモデルB（力学的結合＋能動的な制御結合）で比較する、ビルド不要の教育用Webアプリです。

## 起動

最も簡単なのは `index.html` をブラウザで直接開く方法です。ローカルサーバーを使う場合は次のとおりです。

```powershell
cd posture_coupling_lab
python -m http.server 8080
```

その場合はブラウザで `http://localhost:8080` を開きます。外部API・外部ライブラリは使いません。

## おすすめの見方

まず「おすすめ実験」を順番に選びます。

1. **力学的な交差応答**：制御結合を外し、慣性結合 `M12` のON/OFFを比較します。
2. **ゆっくり一体で揺れる**：0.2 Hzで脚と上体がほぼ同じ位相になる様子を見ます。
3. **制御結合の差を見る**：モデルBのオフ対角制御だけを強め、A/Bの差を見ます。
4. **股関節運動が目立つ**：1.4 Hzで相対的な股関節角と位相差を見ます。

受動弾性・粘性、独立安定化制御、交差制御は別の行列として実装しています。人体図では「物理ばね」として描かず、それぞれが発生する復元トルクと信号経路を色分けします。詳細パラメータは推奨実験を見た後に比較用として変更できます。

## 検証

```powershell
node verify.js
```

全設定・0.1〜2.0 Hzで周波数応答が有限であることを確認します。
