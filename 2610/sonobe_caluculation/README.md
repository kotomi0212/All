# 足関節・股関節モード解析

## 本人専用Web版

https://sonobe-balance-lab.tunedrhino18.chatgpt.site

作成者本人だけが開ける非公開Sitesとして公開しています。ChatGPTでサインインして利用してください。CSVをドロップすると自動で5〜35秒を解析します。区間変更、AP/ML波形切り替え、CSV・JSON・SVGのダウンロードに対応します。

CSVはブラウザー内のメモリーで処理し、サーバーへのアップロードやブラウザーへの自動永続保存は行いません。閉じる・再読み込みすると再選択が必要です。結果を残す場合はダウンロードしてください。解析条件と対応するモード列は下記デスクトップ版と共通です。

Web版のソースは `web/dist/`、ホスティング識別子は `web/.openai/hosting.json` にあります。検証は `node web/test.mjs` で実行できます。

MedicalForcePlateのCSVを読み込み、前後(AP)・左右(ML)それぞれのモード割合と論文指標を表示する、Windows向けローカル解析ツールです。CSVのデータや文字列をコード・指示として実行せず、外部へ送信しません。

## 起動

Python 3.10以上（Tkinter付き）を使用します。初回に `python -m pip install -r requirements.txt` を実行し、`start.bat` をダブルクリックしてください。今回のPCでは必要なライブラリを確認済みです。

1. 「CSVを開く」でMedicalForcePlateのCSVを選ぶ。
2. 初期区間は **5 ≤ t < 35 秒**。開始・終了を変更して「再計算」、または「全区間」を押す。
3. 前後・左右の割合、RMS、RXI、CXIと平均除去後の波形を確認する。
4. 「表示中の結果を保存」でPNG、指標CSV、波形CSV、JSON、注意事項を新規フォルダーに保存する。

短い記録では全区間に切り替えた旨を通知します。CSV選択後に区間を変更しても、再計算するまでは表示・保存とも前回計算した区間です。結果CSVの未定義値は空欄、JSONではnullになります。

GUIなしでも実行できます。

```powershell
python app.py "C:\path\Test_00010.csv" --start 5 --end 35 --output outputs
python -m unittest -v
```

## 論文との対応

Sonobe M, Mitsutake T (2025). *Properties of standing balance control under noisy galvanic vestibular stimulation*. Frontiers in Neurology 16:1500308.
https://doi.org/10.3389/fneur.2025.1500308

参照箇所は2.2節（モードの定義・頭部加速度との関係）、2.3節・Table 1（RMSXI1、RMSXI2、RXI、CXI）、2.5節（5〜35秒の解析）です。

| 入力列 | 意味 | 単位 |
|---|---|---|
| 第1列 | 時刻 | s |
| xix1 / xix2 | AP 足関節 / 股関節モード加速度 | mm/s² |
| xiy1 / xiy2 | ML 足関節 / 股関節モード加速度 | mm/s² |
| axhd / ayhd | AP / ML 頭部加速度（整合性検査用、任意） | mm/s² |

Shift-JIS(CP932)とUTF-8に対応。装置のメタデータ・統計表・繰り返しヘッダーを読み分け、最後のヘッダー以後を時系列として処理します。簡易CSVは上記列名・単位で保存してください。時刻の欠落、重複、非数値、NaNは黙って補間せずエラーにします。

選択区間で各波形の平均を引き、母平均二乗の平方根 `sqrt(mean((x-mean(x))²))` を計算します。

- RMSXI1: 足関節モードRMS
- RMSXI2: 股関節モードRMS
- RXI: RMSXI2 / RMSXI1（論文の比率）
- CXI: 両モードのPearson相関係数
- 足関節割合: 100 × RMSXI1 / (RMSXI1 + RMSXI2)
- 股関節割合: 100 × RMSXI2 / (RMSXI1 + RMSXI2)

**百分率は本ツールが見やすさのために追加したRMS正規化表示です。論文が定義した百分率ではありません。** 動作時間・関節角度・関節トルク・エネルギー・分散の寄与率とは異なります。逆位相の相殺があるため、RMS同士の和は頭部加速度RMSと一致する必要はありません。MLの「股関節」は論文では腰部付近の関節モデルを指します。

## 計算の範囲と整合性

この版では、床反力と頭部IMUから**装置側が推定済みのモード列**を使います。追加フィルタ、再サンプリング、機器側カルマンフィルタの再実装は行いません。身長・体重・性別は装置の推定時に使われるため、ここで再設定はしません。

`rawFx`や`rawAx2`等しかないCSVからは解析しません。生データへの対応には、頭部センサーの指定、取付方向・座標と符号、単位、同期、姿勢・重力補正、装置のフィルタ仕様の確定が必要です。`AccX1`等がゼロの添付CSVについても、それを有効な頭部加速度とみなして計算しません。

平均除去後の `xix1 + xix2` と `axhd`（MLも同様）を比較します。RMSEが頭部RMSの1%（絶対下限0.00001 mm/s²）を超える場合に注意を表示します。これは実装上の整合性確認の目安で、論文の臨床閾値ではありません。出力列の定義はヘッダー・装置内指標との一致から対応付けており、機器ソフトウェアそのものの検証ではありません。

## 添付データによる確認

`Test_00010.csv` は100 Hz、4000点。5〜35秒（3000点）の結果は、装置CSV内のRMSXI1/2、RXI、CXIと数値的に一致することを検証します。全区間では違う値になるため、比較時は解析区間をそろえてください。

MLについてはモード和と頭部加速度に差が認められます。本ツールで無理に補正せず、装置出力のモード割合と整合性注意を併記します。この差がある状態で、百分率を実測頭部運動の厳密な寄与率として解釈しないでください。

原本CSVは変更しません。個人の測定値を含むoutputsフォルダーはGit管理から除外しています。
