# 床を動かす・2リンク姿勢ラボ

`two-link-lab.html` または `index.html` をブラウザで開いて使います。必要なJavaScriptはHTML内に含まれており、HTMLひとつだけを保存・移動して利用できます。利用時に外部ライブラリ・ネット通信・ビルドは不要です。

- 身体の画面を左右へドラッグ：床が滑らかに移動。離すとその位置を保持。
- 手動入力スライダーでも操作でき、フォーカス中は矢印キーが使えます。
- 正弦波：0.2 Hz / 1.2 Hzを比較。
- 視覚背景の回転：床を固定し、背景角を姿勢制御へ入力。視覚の重み0で身体との結合を外せます。
- 一時停止・リセット・姿勢制御の有無を選択可能。モード変更は状態と履歴をリセット。
- 角度・床変位・直近12秒の角度履歴を表示。±20°で小角度モデルの計算を停止。
- 比較条件から「高齢者参考：P比＋遅延差」を選択可能。左の基準身体・右の高齢者参考身体を同一縮尺・同一入力で横に並べて比較し、P比のみ・遅延差のみの要因分離もできます。詳細と出典は [age_model_notes.md](age_model_notes.md)。

## モデル

人体の質量・寸法・重心・慣性は Kiemel, Elahi & Jeka (2008), Table 1 を使用。
https://pmc.ncbi.nlm.nih.gov/articles/PMC2604857/

膝固定の小角度2リンク倒立振子に、床水平加速度の慣性項を追加してRK4で時間積分しています。
人体パラメータは `physics.js`、操作・描画は `app.js`。

立位維持の重力補償＋PD制御と視覚入力の結合は**教育用の追加仮定**です。
制御ゲインは低周波で同相、高周波で逆向きになりやすい例として選定し、人体で同定していません。
同論文の筋活動→関節トルクモデルや感覚フィードバックを再現したものではなく、
「ヒトは必ずこの周波数で股関節戦略へ切り替える」と予測できません。
周波数による制御切り替えはなく、見える変化は固定されたモデルの応答です。
元の `kiemel_demo` は変更していません。

## 検証

```powershell
node two_link_lab/verify.js
node two_link_lab/verify_ui.js
node two_link_lab/verify_age.js
node two_link_lab/verify_standalone.js
```

平衡、初期傾きからの回復、無制御時の不安定性、床慣性項、視覚重み0、床停止後の回復、時間刻み収束、設定例の定性的周波数応答を確認します。

`verify_ui.js` は描画APIを模した環境で操作イベントと計算の結合を検証します。ブラウザの実描画・実ポインター操作の検証ではありません。本セッションではブラウザ安全制限によりローカルHTMLの目視確認は未実施です。

`verify_standalone.js` は配布HTMLから実際の要素ID・初期値・インラインスクリプトを取り出し、外部JSなしで起動することを確認します。起動・実行エラーは画面上部へ詳細を表示します。
