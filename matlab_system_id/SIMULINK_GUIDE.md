`sonobe2025_figure3.slx`を基準モデルとして保持し、実験条件や同定の変更は
「名前を付けて保存」で作ったコピーに加える。原著の支持面入力モデルと、
今後のVR入力モデルを混同しない。変更した式・信号の単位・固定値・同定値を記録する。

メニューが見つからない場合はコマンドウィンドウで次を実行すると、

```matlab

open_system([n '/Body dynamics'],'parameter')
get_param([n '/Visual dynamics'],'Numerator')
get_param([n '/Visual dynamics'],'Denominator')

```

完全に外す場合はコピー側でブロックを右クリックし「マスク」→「マスクの削除」。
外れるのは数式の見た目であり、計算パラメータは残る。

## 論文配置の新しいモデル（推奨）

`sonobe2025_figure3.slx` を開く。上段が視覚経路、中央が遅延付き
フィードバック、下段が身体の伝達関数で、論文Fig.3に合わせた配置。
緑の実行ボタンを押し、右端のCOM scopeを開く。
パラメータはModel Explorer > sonobe2025_figure3 > Model Workspace。
kp/kdは物理単位のゲイン。以前のモデルの正規化Kp/Kdとは異なる。
visual_sign=-1は式(8)・(9)、+1は印刷されたFig.3の視覚経路の符号。
初期設定は-1。遅延はTransport Delay、速度フィードバックは図と同じ微分器。
身体の慣性・重力は一つの伝達関数に含めた。
`buildSonobeFigure3.m` は生成用。既存のSLXがある場合には上書きしない。
前の`sonobe2025_explorer.slx`は比較用として保持している。

別PCで追加した刺激をMATLABで確認するには、このフォルダをパスに追加して
`s = loadStudyStimulus("study_sweep90")` または
`s = loadStudyStimulus("study_multicosine10")` を実行する。
変位・速度・加速度を表示し、timeseriesとして返す。
スイープは計測アプリのJSONサンプル、10周波数は設計CSVを読む。
これは設計信号であり、実測時に適用されたQuestログとは区別する。
VR刺激なので、支持面運動を想定した下記モデルにはまだ接続しない。

`sonobe2025_explorer.slx` をMATLABから開く。
緑の実行ボタンで40秒の例題を計算し、COM scopeをダブルクリックすると
モデルのCOM変位を確認できる。初期値は説明用であり、同定結果ではない。

1. Support accelerationを開く。振幅0.02 m/s²、角周波数2*pi*0.2 rad/sの例題。
2. Support velocityで積分し、Visual target Eq8で目標COM位置を作る。
3. 実際のCOM位置との差に位置ゲインを掛け、速度フィードバックを加える。
4. Reaction delayで反応遅延を入れる。
5. 慣性力と重力を加え、加速度→速度→変位を積分する。
6. COM scopeで出力を見る。

パラメータはModel Explorerの当該モデルのModel Workspaceに保存してある。
Tv（視覚の時定数）、gamma（視覚の重み）、td（反応遅延）、
Kp/Kd（正規化位置・速度ゲイン）を一つずつ変更し、再実行して変化を確認する。
mb/lb/Jbを変えた場合はA=Jb/lb+mb*lbも更新する。
保存すれば変更した値はSLXに残る。生成関数は既存SLXの上書きを拒否する。

出典は園部2025.pdfのp.4583の式(6)–(8)、p.4584 Fig.3。
図では視覚経路の分子が正gammaで、位置誤差の負入力に入っている一方、
式(8)では目標位置へのゲインが負。式(9)も負の視覚寄与を持つため、
本実装では式(8)・(9)に従う。図を完全に同じ符号で写したものではない。
反応遅延はTransport Delayで実装し、Padé近似していない。

このモデルは支持面が実際に動く論文条件。VRだけ動く計測に適用するには、
支持面の慣性力経路と視覚経路を分けたモデルを作り、入力の符号・単位・
出力の定義を合わせる必要がある。現段階では実測データや自動同定は未接続。
先のanalyzeVisualTrialとは独立した、モデル理解用のシミュレーション。
